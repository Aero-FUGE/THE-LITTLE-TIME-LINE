# 日迹

奶油色手账：记录、今日、计时、日迹。无运行时构建依赖。

## 开发与验证

- `npm run dev`：本地端口 4173。
- `npm test`：迁移、计时有效分段、跨日统计、备份结构测试。
- `npm install`、`npx playwright install --with-deps chromium`，启动本地服务后运行 `npm run test:browser`。
- `npm run build`：更新 [静态发布页面](./dist/index.html) 和 [单文件离线版](./日迹_图标已植入_打开即用.html)。根目录页面用于 GitHub Pages；Sites 发布目录为 `dist`。

## 数据升级

旧版四个本地存储键不修改、不删除；首次启动将旧记录、任务、日常和计时迁移至 `riji-unified-v2`，并保留原始数据副本。记录 ID、日期、时间和已有序号保留。新记录按创建日编号。今日安排保存在记录的日期映射中，次日不自动延续。恢复备份按 ID 和更新时间合并，删除使用墓碑以防云端重新出现；恢复前另存一份 `riji-before-restore`。

计时在开始、暂停、继续和结束时立即保存，真实时间戳为计算依据。暂停分段不计入有效时长。跨日统计按执行分段与当地自然日交集计算。结束时先保存可编辑草稿，即使关闭弹窗也不会丢失计时。运行中的计时只属于当前浏览器，云端同步不将另一台设备的计时覆盖到本机。

云端升级需由数据库管理员在 Supabase 执行 [supabase.sql](./supabase.sql) 中新增的 `riji_documents` 建表及 RLS 语句；旧表不删除。登录后读取旧表，并以不覆盖已迁移记录的方式补充缺失数据。新表未配置时，本地保存与备份照常工作，设置中报告云端错误，不伪报已同步。项目不包含数据库管理密钥；本地自动化未使用真实账号验证云端读写。

## 系统限制

iOS 网页在后台或锁屏时可能被系统挂起，无法保证准时播放铃声或通知。已实现前台铃声、通知权限入口、返回时到期检测、超时继续记录及单次提醒。计时结果不依赖后台脚本运行。建议需要准时锁屏提醒时，同时设置系统闹钟。

浏览器自动化覆盖四种屏幕宽度和刷新、关闭页面后重新打开的恢复；不等同于真实 iPhone 锁屏、软键盘或系统通知实机验证。存储不可用或配额不足时会提示保存失败，原数据保持不动。
